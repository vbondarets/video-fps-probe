# Browser benchmark

Generated by `npm run bench` (`scripts/bench/run-bench.mjs`). The built app in `dist/` is served by a local `node:http` server (127.0.0.1, `Cache-Control: no-store`, no compression) and driven over the Chrome DevTools Protocol in headless Chrome with a throwaway profile. Files go through the real file input (`DOM.setFileInputFiles` with absolute paths), so every `File` is disk-backed, as when a user picks files. Times are wall-clock milliseconds on the machine below; `ms` is the analysis inside the worker (`FileResult.io.ms`, from the start of `analyze()` to the result, including any lazy parser chunk load), `UI ms` is measured in the page from the input's `change` event to the DOM update that shows the last result. Every number comes from one run of the bench on one desktop; with a 0.1 ms clock and other processes on the machine, differences of a few tenths of a millisecond between engines or browsers are noise.
